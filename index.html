📋 GSTR-1 — Outward Supplies Return
GSTR-1 contains details of all outward supplies (sales). Download JSON and upload directly to GST portal.
📋 GSTR-3B — Monthly Summary Return
GSTR-3B is a monthly self-declaration return with summary of outward/inward supplies and ITC details.
📋 GSTR-9 — Annual Return
⚠️ Annual return for the full financial year. Mandatory for taxpayers with turnover above ₹2 Crore.
⚡ E-Invoice (IRP) JSON Generator
E-Invoice JSON is generated from saved invoices. Go to Sales Invoices → click ⚡ on any invoice to generate IRN-compatible JSON with QR code.
🚚 E-Way Bill JSON Generator
E-Way Bill JSON is generated from saved invoices. Go to Sales Invoices and use the E-Way Bill option when creating an invoice.
